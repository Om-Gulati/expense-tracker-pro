# Build a Production-Ready Expense Tracker Web Application

Create a modern, full-stack financial management web application called **Expense Tracker Pro**.

## Tech Stack

### Backend

* Python Flask
* Flask REST APIs
* SQLAlchemy ORM
* MySQL database
* JWT Authentication
* Flask-Migrate
* Flask-CORS

### Frontend

* HTML5
* CSS3
* JavaScript
* Bootstrap 5 or Tailwind CSS
* Chart.js for analytics
* AJAX/Fetch API

---

# Project Objective

Develop a highly interactive and visually appealing expense tracking platform that users can depend on daily for managing their finances. The application should feel like a premium financial dashboard.

The design should encourage users to continuously log expenses, check reports, and monitor their financial habits.

# REST API Endpoints

Authentication:

* POST /register
* POST /login
* POST /logout

Income:

* GET /income
* POST /income
* PUT /income/<id>
* DELETE /income/<id>

Expenses:

* GET /expenses
* POST /expenses
* PUT /expenses/<id>
* DELETE /expenses/<id>

Reports:

* GET /reports/monthly
* GET /reports/analytics

Export:

* GET /export/csv
